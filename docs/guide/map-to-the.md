When a quest sends you somewhere, it hands you a map. A **quest map** is drawn like an
[Explorer's Map](explorer-s-map.md): the land sketched in, and the place marked, a structure by the game's own icon for
it, anything else by a **red X**. Its name says where it leads: "Map to the marked place", or the place's own name.

## Where they come from

- **Quest rewards**: a quest can pay in a map to somewhere worth seeing (see [Quest rewards](quest-rewards.md)).
- **Stories**: [The Lost Caravan](the-lost-caravan.md) gives everyone nearby a map to the wreck.
- **Bounties**: taking a bounty gives you a map to the outlaw's hideout (see [Wanted Poster](wanted-poster.md)).
- **Requests**: [The lost heirloom](lost-heirloom.md) comes with a map to where it was lost.

## How it fits with the rest

Places are looked up once, when the quest opens, up to 3000 blocks away, so the map always points to the same spot. If
nobody could find the way, the hall takes the quest down and the chronicle says so.
