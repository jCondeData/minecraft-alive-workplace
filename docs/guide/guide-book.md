The Guide Book is how villagers' jobs work, page by page, with a picture for each of the basics.

## Getting one

Every player gets one the first time they join. Lost it? Craft another from a **book** and **wheat**, anywhere in the
grid.

## Using it

Right-click to read: a page and a picture for each of the basics of villagers' jobs.

For more, this guide starts at [Getting started](getting-started.md).
