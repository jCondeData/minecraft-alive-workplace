# CurseForge kit: the "Cobbleverse + Alive Workplace" modpack

Nothing here is published yet. Before publishing, check Cobbleverse's license and modpack rules on its page; if they
don't allow derivative packs, ask its authors (and keep the Credits section either way).

| File | Where it goes on CurseForge |
| --- | --- |
| `summary.txt` | The modpack's **Summary**. |
| `description.md` | The **Description** (Markdown editor). |
| `logo-512.png` | The project **logo**: Alive Workplace's icon scaled up without smoothing. |
| The pack `.zip` | The first **file**: the CurseForge app's **Export Profile** of the profile set up as the pack (Cobbleverse, Alive Workplace, FTB Quests, Xaero's Minimap and World Map). Tick `mods` and `config`, not saves. |

**Settings:** Class *Modpacks*; game version 1.21.1; loader Fabric; release type *Beta* until 1.0.

**Each update:** update the profile in the app, export it again, upload the new `.zip` as a new file. Players and
PebbleHost then press Update.

**Note:** CurseForge modpacks normally list only CurseForge-hosted mods. While Alive Workplace has no CurseForge project
of its own, its jar travels in the pack's overrides, which review may question; publishing the mod itself
(`docs/store/curseforge/`) fixes that.
