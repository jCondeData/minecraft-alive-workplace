# /workplace leaderboard

```infobox
type: Command
expansion: M33
Syntax: /workplace leaderboard
Who: everyone
Shows: this week's standings so far, board by board
categories: Commands, Village Hall
related: weekly-leaderboard.md, realms.md, economy.md
```

Can't wait for Sunday? Type `/workplace leaderboard` to see how the [weekly leaderboard](weekly-leaderboard.md) stands
so far this week, in the same lines it will be read out in: Biggest, Richest, Happiest, Most Legends and Greatest realm,
the top three of each.

## How it fits in

- **What it reads:** the week's count, which runs as your villages live their days.
- **What stops it:** **Weekly Leaderboard** off in the settings screen; then the command says it's off.
