With the Create mod installed, the schematics you make with Create's tools can be built by the village's builders.
Save a build with the Schematic and Quill, upload it at Create's Schematic Table as you would to print it, and it turns
up at the **Blueprint Table**.

## Two ways in

- **Just open the table.** Every schematic players have uploaded to the server is in the table's list the next time
  anyone opens it, under its file name. You read a line in chat for each new one: "Create schematic Riverside
  Kiosk.nbt (uploaded by Jesse): Imported ... (5 × 5 × 5)".
- **Use the written Schematic on the table.** Right-click the Blueprint Table with the Schematic Create's table gave
  you. Its file is brought in there and then, and the table opens with it in the list. You keep the Schematic.

![The written Schematic used on the Blueprint Table](https://jcondedata.github.io/minecraft-alive-workplace/create_schematic/still-1.jpg)

From there it's a blueprint like any other: look at it in 3D, check its materials, take a copy with a Blank Blueprint
and give it to a builder.

![The builder putting the schematic up](https://jcondedata.github.io/minecraft-alive-workplace/create_schematic/still-2.jpg)

## Good to know

- **Blocks from mods the server doesn't have** can't be built. They're left out, and the chat line says how many and
  which ones ("1 block from a mod that isn't installed became air: steamworks:brass_gauge"), so you know what's missing.
- **Changed your build?** Upload it again under the same name: the blueprint at the table is replaced, not doubled.
- **"The schematic file ... isn't among ...'s uploads on this server"**: the file was deleted from the server, or the
  Schematic came from another server. Upload it again at a Schematic Table.
- **A blank Schematic** has nothing to bring in: write it at a Schematic Table first.
- Machines in a schematic are built in a machine's order, moving parts last, as in
  [Contraptions from a blueprint](create-contraptions.md).
- Without Create, or with the **Create schematics** setting off, the table leaves Create's schematics alone.
